# Status da Sentinex Risk Crypto

Monitoramento público de disponibilidade dos serviços da Sentinex Risk Crypto. As verificações são executadas a cada cinco minutos pelo Upptime.

A página pública será disponibilizada em [status.sentinexrisk.com](https://status.sentinexrisk.com).

O código do Upptime é distribuído sob a licença MIT. Os dados de `history/` seguem a licença indicada nesse diretório.
